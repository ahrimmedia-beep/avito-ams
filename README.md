# Avito AMS

Multi-agent system that runs advertising on Avito, the largest classifieds site in Russia. It writes ads, keeps the budget under control and answers clients in chat.

## Agents

- Copywriter writes ad texts and prepares images.
- Scout studies other ads in the category.
- Budget guard watches spend limits and pacing and sends alerts.
- Chat bot answers client messages and hands warm leads to the owner.
- Analyst sends a daily report to Telegram.

## Stack

Python, asyncio, httpx, Pydantic, Avito API, LLM API, Telegram Bot API, pytest.
